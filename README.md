# 🃏 Cribbage Master Pro

**The Ultimate Cribbage Scoring & Strategy App**

A complete, professional-grade cribbage application with advanced scoring analysis and strategic discard recommendations.

## 🚀 **Live App**

**Try it now:** [https://lutsen07.github.io/cribbage-master-pro/](https://lutsen07.github.io/cribbage-master-pro/)

## ✨ **Features**

### 🎯 **Interactive Hand Scorer**
- Click ranks and suits to cycle through cards
- Complete scoring engine (fifteens, pairs, runs, flush, nobs)
- Detailed visual breakdown showing exactly which cards create each combination
- Famous example hands (Perfect 29, Royal Flush, etc.)
- Statistics tracking with local storage

### 🧠 **Advanced Discard Assistant**
- Analyzes ALL 15 possible keep/discard combinations
- Your crib vs opponent's crib strategy optimization
- Expected value calculations with probability engine
- Ranked results table showing best strategies
- Strategic tips and recommendations

### 📚 **Educational Content**
- Complete cribbage rules tutorial
- Strategy guides for different scenarios
- Visual learning with card combinations
- Interactive examples and tips

### 🎨 **Professional Design**
- Authentic green felt table design
- Smooth animations and hover effects
- Mobile-responsive (works perfectly on phones!)
- Clean, intuitive interface
- Professional card game aesthetics

## 🎮 **How to Use**

1. **Hand Scorer:** Click on card ranks or suits to change them, then hit "Calculate Score"
2. **Discard Assistant:** Set up 6 cards, choose crib owner, analyze all options
3. **Learning:** Check out the tutorial tab for complete cribbage rules
